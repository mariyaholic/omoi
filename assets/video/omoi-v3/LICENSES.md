# Sources and licences

- **Score:** original code in `source/audio/`, adapted from the project's audio lab. It uses numpy and scipy synthesis, with no downloaded samples and no network.
- **Piano voice:** FluidR3_GM SoundFont (`/usr/share/sounds/sf2/FluidR3_GM.sf2`), MIT licence, rendered dry with FluidSynth 2.4.4. FluidSynth is a tool only and is not distributed.
- **Picture:** real omoi UI captures on synthetic data, and original pixel art drawn by `source/render.py`.
