# Interface copy

Owner preference, 2026-11-03: no filler one-liners.

Voice: direct, factual, concise. Neutral tone across all five themes.

- Use labels for navigation and controls. Do not add a sentence that restates the label.
- Omit taglines, slogans, poetic subtitles, generic introductions and decorative footer text.
- Keep text that explains an action, state, consequence, limitation or source of data.

Use: History, Automatic collection, No playback data.
Avoid: quiet routine, a place to return to, make a little room.

Examples:

| Surface | Copy |
|---|---|
| Page heading | History |
| Collection setup | Automatic collection |
| Empty history | No history yet. |
| Playback limitation | Browser history does not include playback position. |
| Preview persistence | Changes reset on reload. |

Visual theme descriptions belong in design documentation; palette swatches and source names are sufficient in the theme picker.
